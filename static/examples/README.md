# Example datasets

Offered on the start screen ("Try an example") so the app can be explored without your own data.

| File | Task | Source |
|---|---|---|
| `breast_cancer.csv` | Classification: `diagnosis` (benign / malignant), 569 records | Breast Cancer Wisconsin (Diagnostic), UCI Machine Learning Repository (CC BY 4.0), the 10 "mean" features, via scikit-learn |
| `diabetes.csv` | Regression: `progression_1y` (disease progression one year after baseline), 442 records | Efron, Hastie, Johnstone & Tibshirani (2004), *Least Angle Regression*, unscaled version via scikit-learn. `sex` keeps the original 1/2 coding, which the source does not document. |
